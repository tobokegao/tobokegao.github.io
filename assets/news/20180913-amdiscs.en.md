## Overview
- Release date: Thursday, September 13, 2018
- Label: AMDISCS: Futures Reserve Label (in cooperation with Cheapbeats)
- Release: "Square Sounds Tokyo 2017 tobokegao Mix (AMDISCS version)" (a mix with video, about 27 minutes)
- About: A mix rebuilt from Tobokegao's Game Boy live set at Square Sounds Tokyo 2017 on September 16, 2017
- Animation: Kabakism, Kekeflipnote, くつわ (Kutsuwa), むらたむうた (Murata Muuta), Mushbuh, つづつ (2z2) and うこんこ (Uconko)

## Afterwards
The next day, September 14, the mix also went up on SoundCloud for free. The description says Tobokegao would be glad if it helped build excitement for that year's Square Sounds Tokyo.
