## Lineup

## About the event
A relaxed event for soaking in Lo-Bit sounds, from the Famicom to the Game Boy, while drinking and chatting. Tobokegao's name came up in the audience survey at the previous edition, and that led to this booking.

## Looking back
Tobokegao played a live set with several songs packed into a single song file (lsdsng), changing sounds on the spot, and also played an LSDj arrangement of a song by パソコン音楽クラブ. Looking back in 2017, Tobokegao wrote that the set did not take the room's acoustics into account and leaned too heavily on favorite melodic songs, so the balance was off for a live show. With that in mind, Tobokegao felt the set at Square Sounds Tokyo 2017 managed a better balance between melody and minimalism, deep bass and clear highs, and the rise and fall in the number of sounds.
