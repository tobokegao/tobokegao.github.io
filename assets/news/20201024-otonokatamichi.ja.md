## 概要
- 始まった日: 2020年10月24日（土）
- 企画: 赤帯さんと Tobokegao の共同 note「おとのかたみち」
- 内容: おたがいに 1万円分の中古 CD を買って相手に送り、届いた CD をレビューし合う
- 枚数: 赤帯さんが 20枚、Tobokegao が 27枚を選び、あわせて 47作品
- 表紙: スレンテンノイさん

## すすめかた
Tobokegao は、赤帯さんから届いた CD を X のリプライで 1枚ずつ紹介し、曲ごとの印象や演奏者などの細かい情報は note に書いていく形にしました。まだすべての CD のレビューは終わっておらず、企画は続いています。
