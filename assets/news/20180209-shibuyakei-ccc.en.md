## Overview
- Release date: Friday, February 9, 2018
- Label: OMOIDE LABEL × Bytedoll Records [OMOIDE 154]
- Title: 渋谷系チップチューンカバーコンピレーション (Shibuya-Kei Chiptune Cover Compilation, 26 tracks)
- Tobokegao's part: Track 21, "Baby, Baby" (a TWEEDEES cover). As supervisor, Tobokegao also helped gather the participating artists.
- Gear: BGB (a Game Boy emulator), LSDj
- Director: YZOX
- Artwork: BluChu

## About the making
Every part of the original felt perfect, so Tobokegao focused on recreating it faithfully on Game Boy. The Bandcamp page lists the gear each artist used.
