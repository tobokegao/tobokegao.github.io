# 0029 アーカイブより新しいポストとリポストは、ブラウザでプロフィールから番号を拾って足す

- **日付**: 2026-10-19
- **決めたこと**: Xのアーカイブ（9/28まで）より新しいポストをメモに入れるため、とぼけがおのログイン済みのChromeでプロフィールを開き、「ポスト」「返信」「リポスト」の各タブからポストの番号だけを読み取る（読むだけで、書き込みやログインの操作はしない）。中身はfxtwitterから取り、`scripts/x_browse.py`でアーカイブと同じ形にして`work/x/all_posts.json`に足し、`x_notes.py`でメモを作り直す。
  - 足したものには`"via": "browse"`の印を付ける。`x_notes.py --archive`で新しいアーカイブを読めば、全部が本物のデータに置き換わる。
  - リポストした時刻と、リポスト自身の番号は、どこにも出ていない。リポストのタブはリポストした順に並ぶので、「それより古いリポストの元のポストがどれも書かれたあと」と考え、後ろに並ぶ元のポストのうちいちばん新しい時刻をリポストの時刻にする（アーカイブの最後より前にはしない）。番号はその時刻から作る。`"est": 1`の印を付け、メモでは時刻に「ごろ」を添える。
- **理由**:
  - アーカイブの取り直しは、とぼけがおの手間が大きい（Xの設定から頼み、数日待つ）。
  - URLを1件ずつ貼る方法（0020の`x_urls.py`）は、1日に数十件あるリポストには向かない。
  - Xの文字をブラウザからそのまま持ち出すと、文の中のURLの問い合わせ部分が、ツールの安全の仕組みに止められる。番号だけを持ち出し、中身はfxtwitterから取ることにした。
  - 「返信」タブには返信しか出ず、リポストは「リポスト」タブにしか出ない（2026年10月のXの作り）。だから3つのタブを読む。
- **守り方**:
  - プロフィールを読むときは、すでに取ったリポスト（アーカイブの`src`）に行き当たるまでさかのぼる。行き当たったところより前が新しい分。
  - 番号のリストとfxtwitterの答えは`work/x/browse/`に置く（Gitには入れない）。
  - 足したあとは`x_notes.py`を回す。
