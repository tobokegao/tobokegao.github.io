# 0010 ページの移り変わりを速く見せる

（Speculation Rules の部分は 0011 で変更。メーターとフォントの先読みはそのまま）

- **日付**: 2026-09-30
- **決めたこと**:
  - `head.html` に Speculation Rules を置く。上のメニューと下のタブバーの 6 ページは、ページを開いた時点で HTML だけ先に取っておく。ほかのページは、リンクにマウスが少し止まるか指が触れた時点で、裏で表示まで用意しておく。
  - タイトルの ANSI アートに使うフォント（`blocks.woff2`、456 バイト）を先読みする。
  - 次のページが 0.3 秒以内に来ないときだけ、小さな窓 `LOAD.EXE` にブロックのメーターを出す（`baseof.html` と `site.js`）。
- **理由**:
  - 1 ページの中身は軽く（HTML は圧縮して 7〜46KB、組み立ては約 0.02 秒）、遅く感じるのは切り替わるたびに画面をまっさらから描き直すためだった。
  - 先読みは Chrome と Edge で働き、スマホの Chrome で速くなったことをとぼけがおが確かめた。Safari と Firefox は対応していないので、待つときのためにメーターも置いた。
  - メーターを 0.3 秒待ってから出すのは、速いときにちらつかせないため。
  - ブラウザは読み込みの進み具合を教えてくれないので、メーターは目安にした。はじめは速く、終わりに近づくとゆっくり進む。
- **守り方**:
  - Speculation Rules は `assets/js/speculation.json` に書く。中身のハッシュを CSP に入れているので、ページの中に直接書かない。
  - Hugo はこの種類の `<script>` の中身をエスケープして別の文字に変えてしまうので、`printf` と `safeHTML` で丸ごと出している。書き方を変えたら、出力のハッシュが CSP と合うか確かめる。
  - メーターは「視差効果を減らす」の設定の人には止まったまま出す。戻るボタンで戻ったとき（`pageshow`）は消す。
  - ページを移動するリンクを JavaScript で作るときは、`showLoading()` を呼ぶ（F1〜F6 のキーと同じ）。
