# 0010 ページの移り変わりを速く見せる

（Speculation Rulesの部分は0011で変更。メーターとフォントの先読みはそのまま）

- **日付**: 2026-09-30
- **決めたこと**:
  - `head.html`にSpeculation Rulesを置く。上のメニューと下のタブバーの6ページは、ページを開いた時点でHTMLだけ先に取っておく。ほかのページは、リンクにマウスが少し止まるか指が触れた時点で、裏で表示まで用意しておく。
  - タイトルのANSIアートに使うフォント（`blocks.woff2`、456バイト）を先読みする。
  - 次のページが0.3秒以内に来ないときだけ、小さな窓`LOAD.EXE`にブロックのメーターを出す（`baseof.html`と`site.js`）。
- **理由**:
  - 1ページの中身は軽く（HTMLは圧縮して7〜46KB、組み立ては約0.02秒）、遅く感じるのは切り替わるたびに画面をまっさらから描き直すためだった。
  - 先読みはChromeとEdgeで働き、スマホのChromeで速くなったことをとぼけがおが確かめた。SafariとFirefoxは対応していないので、待つときのためにメーターも置いた。
  - メーターを0.3秒待ってから出すのは、速いときにちらつかせないため。
  - ブラウザは読み込みの進み具合を教えてくれないので、メーターは目安にした。はじめは速く、終わりに近づくとゆっくり進む。
- **守り方**:
  - Speculation Rulesは`assets/js/speculation.json`に書く。中身のハッシュをCSPに入れているので、ページの中に直接書かない。
  - Hugoはこの種類の`<script>`の中身をエスケープして別の文字に変えてしまうので、`printf`と`safeHTML`で丸ごと出している。書き方を変えたら、出力のハッシュがCSPと合うか確かめる。
  - メーターは「視差効果を減らす」の設定の人には止まったまま出す。戻るボタンで戻ったとき（`pageshow`）は消す。
  - ページを移動するリンクをJavaScriptで作るときは、`showLoading()`を呼ぶ（F1〜F6のキーと同じ）。
