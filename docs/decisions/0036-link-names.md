# 0036 ログの行のリンクには、行き先が分かる名前を付ける

- **日付**: 2026-10-21
- **決めたこと**: 活動ログの行（ニュースの各ページ）のリンクに出す名前を、ホスト名ではなく中身の分かる名前にする。
  - リンクに`name`と`name_en`があれば、それを出す（例: `/reascratch/`は「ReaScratch特設ページ」、Googleの表は「セットリスト」）。
  - なければ、`data/link_hosts.toml`でホストから引く（`t.livepocket.jp`は「チケット（LivePocket）」）。表のキーは、そのホストか、末尾が「.キー」のホストに当たる（`itch.io`は`ikarisu.itch.io`にも当たる）。
  - このサイトの記事（`/post/`）へのリンクは「記事」。
  - どれにも当たらないときは、今までどおりホスト名を出す。
  - 名前は「内容（サービス名）」の形にそろえる（「記事（note）」「作品ページ（IOSYS）」）。サービスの名前だけで分かるもの（Steam、BOOTH、VGMdbなど）は名前だけにする。
- **理由**:
  - 「とぼけがお Tobokegao」「t.livepocket.jp」「docs.google.com」では、押す前に何のページか分からなかった。
  - ホストの表にしておけば、あとから足す行にも名前が付く。同じホストでも中身が違うもの（Googleの表やサイト）だけ、行のリンクに名前を書く。
- **守り方**:
  - 新しいホストのリンクを足したら、`link_hosts.toml`に名前を足すか、そのリンクに`name`を書く。
  - 名前は公開する文章なので、足したら添削に回す。
