# 0005 ニュースは活動ログにする

- **日付**: 2026-09-28
- **決めたこと**: Newsは活動ログ（NEWS.LOG）だけにし、記事はPostsに分ける。手で書いた行（`data/timeline.json`、`data/news.json`）には1行ずつ専用のページを作る。フィードから入った行（`data/autolog.json`）はページを作らず、リリースに直接つなぐ。
- **理由**: フィードの行にまでページを作ると、リリースと同じ内容のページが並ぶだけになる。
- **守り方**: 行のページのアドレスは「日付-日本語のMD5の先頭6文字」で作る（`content/news/_content.gotmpl`と`_partials/timeline.html`で同じ作り方）。日本語を直すとアドレスが変わる。行にフライヤーがあるときは`images`に入れ、行のページのリンクの下に出す。
