# 0007 ログの行のページに本文を書けるようにする

- **日付**: 2026-09-30
- **決めたこと**:
  - 活動ログの行のページ（`/news/日付-…/`）に、本文を書けるようにする。本文は`assets/news/<名前>.ja.md`と`.en.md`に書き、`data/timeline.json`の行に`"article": "<名前>"`を足してつなぐ。
  - 活動の一覧だった記事「Works」は消す。中身はすべて活動ログにあるため。古いURL（`/post/works/`、`/ja/post/works/`）は活動ログへ移す。記事の最後にあったお礼はAboutに移す。
- **理由**:
  - 出演やリリースのくわしい話（出演者、セトリ、感想など）を、その行のページで読めるようにしたい、というとぼけがおの希望。
  - ページのURLは日本語の題名から作られるので、URLをファイル名にすると、題名を直したときに本文とずれる。そのため、URLとは別の名前で指す。
  - Worksは活動ログと同じ内容を二重に持っていて、直すときに片方だけ古くなりやすい。
- **守り方**:
  - 本文の見出しは`##`から始める（`#`はページの題名と同じ格になるため）。
  - 本文は公開する文章なので、出す前に添削に回す。
  - `<名前>`は`日付-短い名前`（例: `20231116-tbk1`）にする。
