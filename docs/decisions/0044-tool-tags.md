# 0044 ツールの記事は1ページのまま、タグのボタンと文字検索で絞り込む

- **日付**: 2026-10-31
- **決めたこと**: 「チップチューンづくりのおすすめツール」の記事の上に、タグのボタンと文字検索を置き、その場で項目を絞り込めるようにする（`{{< tool-filter >}}`、`site.js`）。軸は種類、音源、動く場所、値段の4つ。同じ軸の中はどれか、軸をまたぐと全部に当てはまるものを残す。タグは`data/chiptune_tools.toml`に置く。
- **理由**:
  - 項目が約270あり、目次だけでは「無料のファミコン用」のような探し方ができなかった。
  - ページを分けるより、その場で絞り込めるほうが探しやすい。NEWS.LOGのボタンと文字検索と同じ形にできる。
  - タグを本文の日英それぞれに書くと、同じことを2回書くことになる。全項目を1つのデータファイルへ移す案は、本文の書き写しが大きく、間違いが起きやすいのでやめた。本文はMarkdownのままにして、タグだけを外に置く。
  - 絞り込みの条件をURLに残すと、「無料のファミコン用」を条件ごとリンクで送れる。
- **守り方**:
  - 記事に項目を足したり、名前やリンクを変えたりしたら、`data/chiptune_tools.toml`も直す。項目は太字の名前とリンク先で見つける。日英で名前が違うものは`name_en`を書く。合っていないと`check.py`が止める。
  - 種類のタグは必ず付ける。ほかの軸は、言えることがなければ付けない（特定の音源に限らないプラグインに音源のタグは付けない）。
  - スクリプトが動かないときは、絞り込み欄を出さず、全部の項目をそのまま読めるようにする。
