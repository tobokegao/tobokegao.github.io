# 0045 メモのポストに、検索用の語をClaudeで付ける（組み立ての前に手元で）

- **日付**: 2026-11-03
- **決めたこと**: 自分のポストと返信の1件ずつに、検索で使われそうな語（話題、言い換え、かなと漢字の別の書き方、略した名前の正式名、関係するツールや人や作品、英語の語）をClaudeのAPIで付ける（`scripts/post_topics.py`）。語は`data/memo/topics/YYYY-MM.json`に置き、`layouts/_partials/notes-post.html`がポストの後ろに「⁂」に続けて入れる。画面には出さず（`.np__kw`）、Pagefindだけが読む。検索結果とミニとぼけがおの抜粋では、`notes.js`の`postText`が「⁂」から後ろを切る。
  - APIはこのPCでだけ動かす。鍵はPCの環境変数`TBK_ANTHROPIC_API_KEY`に置き、ActionsのSecretsには入れない。`ANTHROPIC_API_KEY`という名前にすると、Claude Codeがその鍵で動き、ふだんの作業までAPIの料金になる（2026-11-03に起きた）。
  - 全件を一度に処理するときは、Message Batches（料金が半分）で送り（`--batch`）、終わってから取り込む（`--collect`）。新しいポストは、語のないものだけを送る。
  - リポストは他の人の文なので付けない。
  - 同じスクリプトの`--kinds`で、ポストが「どんな質問への答えになるか」の印も付ける。印は決まった6つから選ぶ（rec: 何かをすすめる、howto: やり方やコツ、like: 好きなもの、think: 意見、news: 自分の告知、life: 日々のこと）。印は`data/memo/kinds/YYYY-MM.json`に置き、語と同じ見えない所に`kindrec`のような形で入れる。全件で付けた結果は、印なし20,694件、rec 9,693件、think 8,384件、life 7,703件、news 4,715件、like 4,635件、howto 1,651件（2026-11-03、Opus）。語を比べるだけでは「おすすめは？」「使い方は？」の意図を汲めなかったため。
  - ミニとぼけがおは、次のように答えを選ぶ（`notes.js`の`initMini`）。
    - 質問から時期（「2019年」「2019年の夏」「2010年代後半」「去年」「3年前」「最近」「昔」など）を読み取り、その期間の月のページだけを探す。月のページには、Pagefindの絞り込み用に`month:YYYY-MM`の印を付けた。時期だけの質問には、その期間のポストから選ぶ。
    - 残りの言葉から、ひらがなだけの語（「の」「でしょ」「か」など）、短い英語の語、どんな質問にも出る語（「大丈夫」「教えて」「思う」など）を除く。動詞や形容詞は漢字の部分だけにして（「降り」→「降」）、「降る」のような別の形にも当たるようにする。この漢字だけの語はPagefindには渡さず、点数を付けるときだけ使う（Pagefindは語の全体でしか当たらないため）。「最近雪が降りそうですが大丈夫でしょうか？」に「大丈夫」だけが入ったポストを返したため（2026-11-03）。
    - 自分のポストがあるページ（`kind:own`の印）を先に探し、合うものがないときだけ、リポストも含めて探す。
    - Pagefindは、語が全部どこかにあるページを見つけるだけなので、ページの本文をポストごとに切り分け、ポストごとに、本文と検索用の語に質問の語がどれだけ入っているかで点を付ける。長い語ほど重く（漢字の語は1字でも2字分）、英字の語（名前が多い）は2倍、カタカナの語（物が多い）は1.5倍にし、ほかのポストにも多く出る語（「好き」）は軽くする。半分に届くポストのうち、最高点に近いものから選ぶ。届かなければ「まだ書いてないかも」と答える。
    - 語がポストの本文にあれば満点、検索用の語にだけあれば6割で数える（付けた語より本人の書いたことを優先する）。英字の語は単語として比べる（businessはbusinesspastelに当てない）。ひらがなでも意味のある語（「おすすめ」「かわいい」など）は残す。
    - 質問に「おすすめ」「使い方」「好き」「どう思う」「ライブ」などがあれば、その語は探す語から外し、対応する印の付いたポストに、語の点の合計の6割を足す。印だけの質問（「おすすめは？」）は、印でページを探す。
    - 読むページは、Pagefindの上位4ページと、続く36ページから無作為に4ページ。上位だけだと同じ答えばかりになり、無作為だけだと合うポストのあるページを読み落とす。
    - 答えには、抜粋ではなくポストの本文を出し、質問の語に印を付ける。長いポストは最初の語のまわりを240字まで出す。
    - 公開した日に、「冬タイヤ大丈夫でしょうか？」に「冬」だけが入ったポストを返したため（2026-11-03）。
- **理由**:
  - Pagefindはポストに書かれた語でしか当たらないので、「M8の使い方」のように本文にない言い方では、合うポストがあっても見つからなかった。
  - 0032のとおり、ページから毎回AIを呼ぶ形はとらない。鍵が公開されるうえ、言っていないことを本人の口調で言ってしまうおそれがある。語を付けるのは探すためだけで、答えは今までどおり本人のポストそのものを出す。
  - 語をページに見える形で出すと、本文と見分けがつかず、本人が書いたように読める。見えない形にして、抜粋からも切る。
  - Max 5xに付く毎月のAPIのクレジットは、Claude Codeでは使えない。スクリプトから呼べば、ふだんの作業の枠を減らさずに使える。
- **守り方**:
  - 語は探すためだけに使う。語を画面に出したり、語からポストの紹介文を作ったりしない（作るなら新しい決定にする）。
  - 指示（`SYSTEM`）では、ポストの中身にないことを推し量らせない。意見や口調の説明を付けさせない。
  - 全件を送る前に、`--estimate`で件数と料金の見積もりを出し、とぼけがおに確かめる。モデルは`TBK_TOPICS_MODEL`で選ぶ。
  - 抜粋の窓が語の部分だけにかかると、「⁂」が入らず語が見えてしまう。語は1件20語までにし、長くしない。
