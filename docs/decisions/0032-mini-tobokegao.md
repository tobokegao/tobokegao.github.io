# 0032 メモのページに、ポストを引いて答える「ミニとぼけがお」を置く（AIは使わない）

- **日付**: 2026-10-19
- **決めたこと**: メモのいちばん上のページに「ミニとぼけがお」を置く。訪れた人が言葉を入れると、メモの検索（Pagefind）で合うポストを探し、とぼけがおの返信の書きぶり（出だしの言葉、「…！」、うしろのかっこ）の決まった言い回しで、そのポストを紹介する（`assets/js/notes.js`の`initMini`）。
  - 絵は、とぼけがおが選んだ「diary」のドット絵148点から、表示のたびにランダムに出す。元の絵は`data/minitobo.json`に並べ、`scripts/minitobo_art.py`で240pxの枠に合わせたWebPにする（元が120px以下の小さなドット絵だけを整数倍に拡大して可逆圧縮し、くっきり見せる。1ドットずつ描いた大きな絵は縮小し、細かい画面向けに2倍・3倍まで（元の大きさが足りなければそこまで）の版も作る。GIFは動くWebPと、動きを減らす設定の人向けの止まった1コマ目）。拡大がいる絵（320pxほどのドット絵を拡大して投稿したものなど）は、Scale2xで大きくしてから縮め、ななめの線の段差をなめらかにする（色は増やさない）。縮めた絵は、ドットをくっきり保つ表示（pixelated）にしない。スマホで240pxを引き伸ばすと粗く見えたため（2026-10-19）。
  - 答えたポストの絵は、組み立てのときに作る月ごとの絵の一覧（`/memo/m/`、自分のポストは1か月で大きくても約20KB）から出す。ポストのある月や話題のページを丸ごと読むと、数MBあって遅かった。
  - 「メモの中から自動で選んで答える。とぼけがお本人の返事ではない」と、すぐ下に書く。
- **理由**:
  - サイトはGitHub Pagesで、AIの鍵を置けない（置くと公開される）。中継のサーバーを立てる案は、費用、いたずら、言っていないことを本人の口調で言ってしまうおそれがあり、とらなかった。
  - 答えをとぼけがおが本当に書いたポストに限れば、作り話が出ない。
- **守り方**:
  - 言い回しを足すときも、意見や約束を作らない。ポストの日付と中身を紹介するだけにする。
  - 絵を足したり外したりしたら、`data/minitobo.json`を直して`minitobo_art.py`を回す。
