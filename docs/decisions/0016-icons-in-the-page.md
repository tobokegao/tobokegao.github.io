# 0016 ドット絵のアイコンはページの中に持つ

- **日付**: 2026-10-01
- **決めたこと**:
  - ドット絵のアイコン（配信先の小さいアイコン、トップページの大きなリンクのアイコン）は、別の SVG ファイルに置いて `<use href="ファイル#id">` で指すのをやめ、`<symbol>` を集めた見えない `<svg>` としてページの中に置き、`<use href="#id">` で指す（`icon-sprite.html`）。
  - 小さいアイコンの集まりは `baseof.html` で `<main>` の外に 1 つ置き、ページを移っても残す。大きいアイコンの集まりはトップページ（`home.html`）の中に置く。
- **理由**:
  - 別のファイルを指す `<use>` は、そのファイルが読まれて解かれるまで描かれない。とぼけがおのスマホでは、トップページへ移ったとき、SNS のアイコンだけがかなり遅れて出ることがあった。ページの中にあれば、HTML が入った瞬間に描かれる。
  - 大きいアイコンの集まりは約 180KB（圧縮して 18KB）あるので、全ページには置かず、使うトップページだけに置く。
- **守り方**:
  - アイコンを足したら `icon-sprite.html` の一覧に足す。`<use>` の中には CSS のクラスが届かないので、色は `--px-outline` などのカスタムプロパティを使ったインラインスタイルで渡す（`icon-sprite.html` の `$fix`）。
  - `site.js` の `absolute()` は `#` で始まる `href` に触らないので、相対リンクのプレビューでもそのまま動く。
