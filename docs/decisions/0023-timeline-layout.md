# 0023 年表を「なりたち」にし、線は直角だけで引き、段はつながる相手の近くに置く

- **日付**: 2026-10-16
- **決めたこと**: 年表（0021）の名前を「なりたち / Roots」にし、URLを`/memo/roots/`、窓を`ROOTS.SVG`にする。題名はのちに「音楽相関図: なりたちツリー / Music Roots Map」にした（「なりたち」だけでは何のなりたちか分からなかった）。描き方は次のようにする。ライブラリは使わず、`assets/js/notes.js`の中で描く。
  - 線は直角だけで引く。親の右から出て、子の手前20pxで縦に曲がり、子に入る。子が親の右端より左から始まるときは、子の段の上か下のすき間を通って戻る。
  - 親の段をまっすぐ右へ進むと、同じ段のほかの箱の後ろを通ってその箱から出ているように見えるときは、段の下（または上）のすき間を通って回る（歌謡曲の右からR&Bへつながって見えた）。
  - 同じ位置で曲がる線は、行き先の子ごと、線の種類ごとに4pxずつずらす。同じ子に入る同じ種類の線は1本の縦線にまとめる。
  - 親→子は青の実線。元→影響は紺の線に黄色の点を重ねた点線（夜は灰色の線にレモン色）。矢印は8×14pxの段々の三角。線と矢印はにじまないように描く（`shape-rendering: crispEdges`）。
  - 箱のすき間は縦横24px。箱の幅は日英の広いほうに合わせる。年と数は「1968年生まれ」「ポスト383件」（英語は「born in 1968」「383 posts」）と2行に分けて書く。1行にすると箱が広がり、段が増えて縦に長くなった。生まれた年のない話題は、最初のポストの年で「2014年から」（「since 2014」）。
  - 横の位置: 10年ごとに区切り、その10年の幅を「縮尺×10 ＋ 縮尺×3×その10年のページ数」にする。混んだ時代ほど広く、空いた時代は短い。年の目盛りは10年ごと（幅が128px以上なら5年にも）。40年より離れた年のあいだは詰めて、切れ目を入れる。目盛りは、いちばん新しい年のある10年で終わる（まだ来ていない2030年は出さない）。縮尺は、枠の中で指2本を広げ縮めするか、Ctrlを押しながらホイールを回して変える（キーボードでは＋と−）。初めはバー（「時代の幅」）だったが、スマホでは指で広げるほうが自然なのでやめた。指の動きに合わせて、その場で1段ずつ描き直す。初めは指を動かしているあいだ図を伸ばして見せていたが、スマホで試すとドットの字が縦や横に間延びした。描き直すと指の下の箱がページから外れ、ブラウザはその箱にだけ指の動きを伝えるので、触れた箱そのものでも動きを聞く。スマホでは、ページをいちばん上にしたとき、窓の下端（出典の行も含めて）が下のメニューの上で終わるように枠の高さを決め、図を見るのにページを動かさなくてよいようにした。PCでは窓に合わせると枠が低くなりすぎるので、画面の高さの75%のまま。指していた年は、広げる前と同じ位置に残す。開いたときは、縦は名前だけの1行にして、いちばん新しい年（右端）を見せる。横の縮尺は、図の高さが枠に収まるいちばん狭いものを、描いて測って選ぶ（ジャンルが増えても縦にスクロールしなくて済むように）。段の数は枠に収まる数までにし、空いた段がない箱は、新しい段を足す代わりに、いちばん早く空く段に少し右へずらして置く（同じ年のジャンルが多いと縦に積み重なって、スマホではどこまで広げても収まらなかった）。ずらすのはその年から3年ぶんまでで、それより遠くなるときは段を足す。それでも収まらないときは、5段階広げても1段ぶんしか低くならない最初の縮尺で止める。年の目盛りは図の上の帯に描き、下へスクロールしても枠の上に残す。ジャンルを一度選んだあとは、枠の高さが変わっても初めの縮尺を選び直さない（窓を閉じると枠の高さが戻り、選び直すと右端に戻って、見ていた場所を見失った）。最初に見せる右端は、目盛りの端ではなく、いちばん右の箱にそろえる（ポストのある話題をすべて出すと、最後の10年の幅が箱よりずっと広くなり、右端に何も映らなかった）。図の上に、ジャンルを名前で探す枠を置く。打つと、いま図に出ているもの（ジャンルだけのときはジャンル、ポストの話題も含むときは話題も）から、名前が合うものを枠の下に縦の一覧で出し、選ぶとそのジャンルを選んで窓を開く。初めはブラウザの候補（datalist）を使い、年のない話題の名前が一致すると表示を切り替えていたが、スマホでは候補が横一列にしか出ず、打っている途中の文字が話題の名前と一致して、ジャンルだけの表示から勝手に切り替わった。検索では表示を変えない。縦は横と別に変える。指を横に広げ縮めすれば年の幅、縦なら段の高さが変わり、斜めなら両方が変わる（PCはCtrlとShiftを押しながらホイール。ただしWindowsのChromeなどで縦が変わらないことがあったので、PCには「横」「縦」の＋・−のボタンも置く。指で触る画面には出さない。タッチパッドで2本指を広げる操作はCtrl＋ホイールとして届き、Shiftは付かないので縦は変わらない。案内の行からは「縦は＋Shift」を外した）。初めは横に合わせて縦も縮めたが、横を狭めると同じ年代に入りきらない箱が下の段へ回り、高さは8割ほどにしかならなかった。縦を縮めるときも字は縮めず（升目どおりの大きさでだけ使う決まり）、箱から行を減らす。名前・年・件数の3行、名前と年の2行、名前だけの1行の3段階で、段のすき間も24・16・8pxと狭める。名前だけにすると高さは4割ほどになる。縮めすぎて年の数字が重なるところは、線だけを引いて数字を省く。線は、子の箱の手前で曲がる場所が親の箱より左になるときも、矢印の入る余地があれば親の箱のすぐ右で下ろし、数pxだけ左へ戻る小さな段を作らない。
  - 段の決め方: 年の順に、空いている段のうち、つながる相手の段の平均（重心）にいちばん近い段に置く。3回くり返し、2回目からは後ろの相手の位置も使う。空いている段がないときだけ新しい段を開く。
  - 大ジャンルは6つ（Jazz、House、Rock、Hip Hop、Techno、Bass Music。ノートの`major = true`と`color`。初めはTranceとHardcore Technoだったが、属するジャンル（下位をたどった数）と影響先が少なく、TechnoとBass Musicに替えた。2026-10-17）。色はTRACKMENTOの「リソ」の6色（夜は「ナイト」の6色）。図の上に、大ジャンル自身の年から縦線を引き、名前を色の旗で出す（右端を2pxの段で燕尾に切り欠く。初めは四角い札で、大ジャンルの箱と見分けがつかなかった。旗を押すと、その大ジャンルの窓が開く。重ならない札は同じ段に並べる。初めは属するジャンルのいちばん早い年にしたが、New Orleans JazzがJazzより早い年にあり、札がJazzの箱から離れて見えた）。属するジャンル（下位をたどった先）の箱の枠もその色にし、2つ以上に属すときは新しいほうの色にする。大ジャンルそのものの箱は色で塗る。札と塗った箱の字は、青と朱では白、ほかは暗い色。
  - 生まれた年が年代の一部しかわからないジャンルは、ノートに`era`を書く（`x`は年代だけ、`x2`は前半、`x3`は半ば、`x4`は後半。`born`は年代＋0・2・5・7年で、そこに置く）。箱と窓は「1990年代後半生まれ / born in the late 1990s」、ジャンルのページは「1990年代後半 / Late 1990s」と書く。ざっと（zatto）さんの音楽ジャンルWikiの「年代の時期」を採り入れた。初めは初め・終わりも入れて5つに分けたが、英語ではEarly・Mid・Lateの3つに分けるのがふつうなので、3つにした。
- **理由**:
  - 「年表」は出来事を年の順に並べる表のようで、ジャンルの親子をたどる図には合わなかった。「系図」は硬いので、やわらかい「なりたち」にした。
  - なめらかな曲線と紫の破線は、DOSの画面に合わなかった。罫線（─│┌）のような直角の線にそろえた。
  - 黄色の細い線は白い地ではほとんど見えない。紺の線に黄色の点を重ねれば、白い地でも見え、下から黄色で照らす決まり（0002）とも合う。
  - 曲がり角が子のすぐ手前（6px）だと、矢印が縦線とくっついて見えた。
  - 前は空いているいちばん上の段に詰めていたので、親子が遠い段に離れ、線がからんでいた。グラフを段に分けて描く方法（Sugiyama法）の重心の手順だけを借りた。
  - elkjs（段分けと直角の線を両方持つライブラリ）は大きく、横の位置を年で決める作りと合わないので使わなかった。
  - 等間隔の目盛りだと、ジャンルの多い1980〜2000年あたりに箱が積み上がり、段が増えて縦に長くなった。
  - 空いている段がなくても新しい段を開ける書き方を試したところ、段が増えて縦に間延びした。そこで、新しい段は空いている段がないときだけにした。
- **守り方**:
  - 年が分からないジャンルに仮の年（1900など）を入れると、同じ位置に箱が積み上がり、長い線が増える。年は確かめたものだけを入れる。
  - 年は、呼び名ができた年や店ができた年ではなく、音楽そのものが始まった出来事の年にする（Wikipedia英語版とBritannicaで確かめる）。総称のもの（Club Music、サンプリング音楽、実験音楽）や、資料で食い違うもの（Italo Disco）には年を入れない。2026-10-16に、1900が入っていた12件をこの決め方で直した（Hiphop 1973、R&B 1949、Synth Pop 1978、Disco Music 1974、Contemporary R&B 1979、EBM 1981、Garage House 1985、New Beat 1987）。渋谷系は音楽の始まりが「80年代末〜90年代初め」としか分からないので、例外として呼び名が使われ始めた1993年にした（とぼけがおが選んだ）。
  - 色は`--rel-up`、`--rel-src`、`--rel-lit`を通して使う。
