# 0023 年表を「なりたち」にし、線は直角だけで引き、段はつながる相手の近くに置く

- **日付**: 2026-10-16
- **決めたこと**: 年表（0021）の名前を「なりたち / Roots」にし、URLを`/memo/roots/`、窓を`ROOTS.SVG`にする。描き方は次のようにする。ライブラリは使わず、`assets/js/notes.js`の中で描く。
  - 線は直角だけで引く。親の右から出て、子の手前20pxで縦に曲がり、子に入る。子が親の右端より左から始まるときは、子の段の上か下のすき間を通って戻る。
  - 同じ位置で曲がる線は、行き先の子ごと、線の種類ごとに4pxずつずらす。同じ子に入る同じ種類の線は1本の縦線にまとめる。
  - 親→子は青の実線。元→影響は紺の線に黄色の点を重ねた点線（夜は灰色の線にレモン色）。矢印は8×14pxの段々の三角。線と矢印はにじまないように描く（`shape-rendering: crispEdges`）。
  - 箱のすき間は縦横24px。箱の幅は日英の広いほうに合わせる。年と数は「1968年生まれ」「ポスト383件」（英語は「born 1968」「383 posts」）と2行に分けて書く。1行にすると箱が広がり、段が増えて縦に長くなった。生まれた年のない話題は、最初のポストの年で「2014年から」（「since 2014」）。
  - 段の決め方: 年の順に、空いている段のうち、つながる相手の段の平均（重心）にいちばん近い段に置く。3回くり返し、2回目からは後ろの相手の位置も使う。空いている段がないときだけ新しい段を開く。
- **理由**:
  - 「年表」は出来事を年の順に並べる表のようで、ジャンルの親子をたどる図には合わなかった。「系図」は硬いので、やわらかい「なりたち」にした。
  - なめらかな曲線と紫の破線は、DOSの画面に合わなかった。罫線（─│┌）のような直角の線にそろえた。
  - 黄色の細い線は白い地ではほとんど見えない。紺の線に黄色の点を重ねれば、白い地でも見え、下から黄色で照らす決まり（0002）とも合う。
  - 曲がり角が子のすぐ手前（6px）だと、矢印が縦線とくっついて見えた。
  - 前は空いているいちばん上の段に詰めていたので、親子が遠い段に離れ、線がからんでいた。グラフを段に分けて描く方法（Sugiyama法）の重心の手順だけを借りた。
  - elkjs（段分けと直角の線を両方持つライブラリ）は大きく、横の位置を年で決める作りと合わないので使わなかった。
  - 空いている段がなくても新しい段を開ける書き方を試したところ、段が増えて縦に間延びした。そこで、新しい段は空いている段がないときだけにした。
- **守り方**:
  - 年が分からないジャンルに仮の年（1900など）を入れると、同じ位置に箱が積み上がり、長い線が増える。年は確かめたものだけを入れる。
  - 年は、呼び名ができた年や店ができた年ではなく、音楽そのものが始まった出来事の年にする（Wikipedia英語版とBritannicaで確かめる）。総称のもの（Club Music、サンプリング音楽、実験音楽）や、資料で食い違うもの（Italo Disco）には年を入れない。2026-10-16に、1900が入っていた12件をこの決め方で直した（Hiphop 1973、R&B 1949、Synth Pop 1978、Disco Music 1974、Contemporary R&B 1979、EBM 1981、Garage House 1985、New Beat 1987）。
  - 色は`--rel-up`、`--rel-src`、`--rel-lit`を通して使う。
