# 0019 日本語の文では、英字・数字の前後に半角スペースを入れない

- **日付**: 2026-10-01
- **決めたこと**:
  - サイトに出す日本語の文では、英字・数字と日本語のあいだに半角スペースを入れない（「Bandcamp で」ではなく「Bandcampで」、「12 曲」ではなく「12曲」）。TRACKMENTO でも同じにする。
  - 次のものは、書かれているとおりに残す。
    - 「」『』の中の題名
    - 曲目やセットリストの番号付きの一覧
    - タイムテーブルの時刻と出演者のあいだ
    - 名前の一部になっているスペース（DJ さうすまうぅん など）や、英語の言い回し（by、from）
    - 住所の郵便番号や番地のあとのスペース
    - インタビューの記事（ほかの人の言葉をそのまま載せているため）
  - 日本語の文では「ゲームボーイ」ではなく「GAMEBOY」と書く。ゲームボーイアドバンスのような製品名と、「」の中は元のまま。
  - ログの行（`data/timeline.json`）には、行のページのアドレスになる `id` を持たせる。今までは `ja` の文から作っていたので、文を直すとアドレスが変わってしまっていた。今ある行には、今までと同じ `id` を書き込んだので、アドレスは変わっていない。
- **理由**:
  - とぼけがおの指定。日本語の添削ツール（yomiyasu）を試したとき、この書き方に直す指摘をとぼけがおが採った。「GAMEBOY」も、とぼけがおが選んだ書き方。
- **守り方**:
  - 新しく書く文章もこの書き方にする。
  - `scripts/check.py` は、変えた日本語のファイルにスペースが残っていると「知らせ」で伝える。名前などで残すものもあるので、止めはしない。
  - ログの行を足すときは `id`（日付 8 桁-英数字 6 字）を付ける。`x_to_timeline.py` は自分で付ける。ないと `check.py` が止める。
