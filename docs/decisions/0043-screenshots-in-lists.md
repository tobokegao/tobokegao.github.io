# 0043 記事の箇条書きに画像を入れるときは、1枚ずつ中央に置き、項目のあいだを広げる

- **日付**: 2026-10-30
- **決めたこと**: 記事の箇条書きの項目の中に画像を入れるときは、画像を1枚ずつ中央に出す（`.prose li img`）。画像の入った箇条書きでは、項目と項目のあいだを32px空け、項目の中の小さな箇条書きの下も16px空ける（`.prose ul:has(img)`）。最初の記事は「チップチューンづくりのおすすめツール（2026年10月版）」（`content/post/2026-chiptune-tools.md`）。
- **理由**:
  - ツールを紹介する記事で、項目ごとに画面の画像を付けた。画像が文のあとに続けて並ぶと、どの画像がどのツールのものか分かりづらかった。
  - 記事の中で項目のあいだに空行を入れる（段落のある箇条書きにする）だけでは、広がりが足りなかった。
  - `:has(img)`で、画像の入った箇条書きだけを対象にする。画像のない箇条書きの見た目は今までどおり。
- **守り方**:
  - 画像は表示する大きさのWebPにして、`static/img/<記事の名前>/`に置く。箇条書きの中では、横560px・縦420pxまで。ドット絵の画面は整数倍でだけ拡大する。
  - 画像は項目の文のすぐ次の行に、項目の文と同じ字下げ（`- `の分だけ下げる）で`<img>`を書く（`width`と`height`も付ける）。
  - よそから借りた画像は、出どころを記事の最後に書く。公式ページにない画像を作者や他の人のSNSの投稿から使うときは、投稿へのリンクを付ける。作者本人でない人の投稿は、許可をもらってから使う。
  - 項目の多い長い記事には、書き出しのすぐ下に目次を置き、`<nav class="toc">`で囲んで枠を付ける（`.prose .toc`、2026-10-30に追加）。見出しには`{#ja-…}`・`{#en-…}`の名前を付け、見出しの文を直しても目次のリンクが切れないようにする。
  - 記事（post）のページには、右下に「上へ戻る」ボタンを置く（`.totop`、2026-10-30に追加）。押すと記事の題名へ移る。本文の上に重なっても読めるよう、窓の色の地と枠を付ける。
