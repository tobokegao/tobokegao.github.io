# 0012 リリースと動画の題名に英語の表示を足す

- **日付**: 2026-10-01
- **決めたこと**:
  - 英語表示のとき、リリースと動画の日本語の題名を、英語の題名に切り替えて出す。英語の題名は `data/titles_en.json` に、もとの題名をそのまま鍵にして書く（`titles`）。アーティスト名も同じファイルに書く（`artists`）。
  - 説明の文になっている題（「MIDIと同期させたYTPMVを作る その3」など）は英訳する。曲名と人名はローマ字にする。英語の題がすでにあるもの（Bandcamp や SoundCloud の英題）は、そちらを使う。
  - 表にない題名は、もとの題名のまま出す。
  - 活動ログのうちフィードから作る行（`data/autolog.json`）も、英文にはこの表の英語の題名を使う（`scripts/fetch_feeds.py` の `build_autolog`）。手で書く行（`data/timeline.json`）は、`en` に日本語を残さず、ローマ字か英訳にする。
  - ブラウザのタブの題名も、表示の言語に合わせて切り替える。`<title>` に `data-ja` と `data-en` の両方を持たせ、`assets/js/site.js` が切り替える。
- **理由**:
  - 英語表示にしても、リリースと動画のページは題名がほとんど日本語のままだった、というとぼけがおの指摘。
  - `data/releases.json` と `data/items.json` はフィードから作り直されるので、そこに英語を書くと消える。別のファイルにしておけば、作り直しても残る。
- **守り方**:
  - 題名が変わると、鍵が合わなくなって英語が出なくなる。新しいリリースや動画が増えたら、英語表示で日本語が残っていないか見て、表に足す。
  - 人名の読みは推測しない。わからないものは、とぼけがおに確かめる。
