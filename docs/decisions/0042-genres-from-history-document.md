# 0042 大衆音楽の歴史の文書から、ジャンルをなりたちに足す

- **日付**: 2026-10-26
- **決めたこと**: 大衆音楽の歴史をまとめた文書（Googleドキュメント。作者の許可あり）に出てくるジャンルのうち、なりたち（0023）にまだないものを、ジャンルのノートとして足す。
  - 足すのはジャンルだけ。楽器、機材、出来事（ウード、DX7、冷戦など）は足さない。
  - 文書から取るのは、どのジャンルを足すかと、親子・源流のつながりの見当だけ。生まれた年は、Wikipedia英語版の情報欄（cultural origins）と冒頭の文で確かめる。年代の一部しか分からないものは`era`を使う（0023）。
  - Wikipediaで年代が分からないものは、本文とBritannicaなど英語の資料で探す（Tango 1880年代、Honky-tonk 1940年代、Operetta 1848、Sertanejo 1929、Canzone Napoletana 1839、Roots Reggae 1970年代前半、Latin Trap 2007）。Britannicaでも年代まで決まらないもの（Son Cubano、Cuban Rumba、Mariachiは「1700年代末か1800年代初め」、Ranchera、Chansonは中世のものしか載っていない）は足さない。別の項目に転送されるもの（Vocal trance → Trance、Dutch house → Electro house）も足さない（0024）。
  - 足したノートには`credit = "history"`と`unverified = true`を付ける。ページには、ざっとさんとは別の行で文書のクレジットを出す（`genreCredit_history`）。`credit`の値ごとに`strings.toml`の`genreCredit_<値>`を引く（`zatto`だけは前からの`genreCredit`）。
  - つながりはDBpediaが優先（0024）なので、ノートに書いたつながりはDBpediaが結んでいない組み合わせにだけ効く。
- **理由**:
  - 文書の年は「1940年代」「19世紀末」のような書き方が多く、箱を置く年としては粗い。年の決め方（0023）に合わせて、確かめられる資料で決めた。
  - 「マンボ」は「マンボウ」にも当たるので、Mamboは`match = "tags"`にした。
- **守り方**:
  - 作者の希望で、名前は出さない（クレジットは「作者名は非公開」）。ノートやコミットにも名前を書かない。
  - 見送ったジャンルを足すときは、始まりの年を確かめられる資料を見つけてからにする。
