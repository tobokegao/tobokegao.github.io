# 0006 Xのアーカイブから過去の出演を拾う

- **日付**: 2026-09-29
- **決めたこと**: サイトをあまり更新していなかった時期の出演や告知を、Xのアーカイブから拾ってログに足す。流れは`import_x_archive.py`（候補を選ぶ）→ `review_x.py`（載せるかを人が選ぶ）→ `x_to_timeline.py`（文を書いてログに入れる）。
- **理由**: Xの検索は1回に20件ほどで打ち切られるので、全部を拾うにはアーカイブが要る。アーカイブは画像や動画を含めて数百GBあるため、zipを展開せずに投稿のファイルだけを読む。
- **守り方**:
  - 候補の点数は、実際の投稿（約190件と音MAD関係の75件）で確かめて決めた。「DJ」「ライブ」のような語は他の人のイベントの感想にも出るので軽くし、「出演します」「流します」のような自分が出る言い回し、自主企画の名前（ToBeKontinued、音TOUCH）、ログにある名前を重くしている。しきい値は6。
  - 同じイベントについての投稿（告知、出演者紹介、タイムテーブル、お礼）は別々の候補になるので、1つのイベントにつき1件を選ぶ。
  - お客さんとして行っただけのイベント（例: MAD DRIFTの無印）は載せない。
  - 作業用のファイルは`work/`に置き、Gitに入れない。
