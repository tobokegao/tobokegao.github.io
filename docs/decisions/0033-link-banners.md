# 0033 相互リンク用のバナーを、昔の個人サイトのバナーの作りでGIFにする

- **日付**: 2026-10-20
- **決めたこと**: トップページのいちばん下に「LINKS.HTM」の窓を置き、相互リンク用のバナーを実寸で並べる。大きさは468×60、200×40、88×31の3つ。それぞれに、絵（描いた顔と、32×32のドット絵を整数倍にしたもの）と配色（昼はサイトの色、夜はTRACKMENTOの色）の違う4つの版がある。バナーは`scripts/link_banners.py`で作り、`static/img/banners/`に置く。
  - 形は、90年代後半から2000年代の個人サイトのバナーにならう（@memoriesofhpが紹介した200×40の920枚、88×31の約3500枚）。200×40は、ミニとぼけがおの顔を寄せて切り、左に名前を置く。468×60は200×40の字を2倍にし、頭を切らずに3人並べる（1つの顔を横長の帯に切ると、上下が切れすぎた）。描いた顔の版は、絵の地が黄・青・黄の順になる組み合わせにする。イラストは昼と夜で別の絵を使い、同じ絵が2回出ないようにする。468×60のドット絵の版は、3つの絵（129、128、首を左右に振る139）を並べたまま、それぞれの元のアニメーションを元のコマの長さで動かす（20msごとの共通の時間軸で4.8秒ひと回り。129と139は継ぎ目なくつながり、128だけひと回りの終わりに最後のコマを飛ばす。パレットは全コマ共通にして、動いたところだけを書き足す）。絵は字のかたまりと同じ行に置き、字の右の端からは字の左と同じ余白、上・右・下は同じ余白で囲む。縮めたときと減色したときに絵の縁が余白へにじむので、どちらのあとにも余白を地の色で塗り直す。88×31は、無地に名前と小さな顔。
  - 絵の劣化はTRACKMENTOの広告バナー（`onet5.py`）と同じ。4倍で組み、LANCZOSで2倍、最近傍法で1倍に縮めて輪郭をギザギザにする。各色を5ビットにし、コマごとに22色のパレット（サイトの色は必ず入れる）とFloyd-Steinbergのディザにする。ディザはイラストの版だけにかける（服の網点が、ディザなしでは平らな面になる）。ドット絵の版は元が4色で、ディザの有無で見た目が変わらないのでかけない。
  - 字はフォントを使わず、1ドットずつ手で置く（`scripts/link_letters.py`）。縦線は大きい字で3ドット、小さい字で2ドット。字の中のすき間は1ドット以上あける。字間は、角を1ドット欠いただけの丸い字を縦線と同じに扱い、「T」の腕の下と、右が開いた「k」のあとの「e」だけを詰める。
  - 絵が白に溶けるところは、ぼかしではなく網点を3段（4分の3、半分、4分の1）にする。
  - 3コマで顔が替わる（1コマ1.5秒）。配るのはGIFで、1コマ目だけの「静止画版」のGIFも配る。サイトの中で動きを減らす設定の人には、静止画版を出す。
  - ファイル名は大きさの数ではなく`large`・`medium`・`small`にする。名前に「468x60」があると、広告ブロックが広告とみなして止める（手元のブラウザで実際に止まった）。
  - 468×60はスマホの幅に入らない。縮めるとドットがにじむので、縮めずに横にスクロールさせる。
- **理由**:
  - 相互リンクのバナーは相手のサイトに貼られる。昔ながらのGIFなら、どこでも動き、当時のバナーと並べても浮かない。「画像はWebPにする」の決まりは、サイトの中で見せる画像のためのもので、配るバナーには当てはめない（`check.py`は`static/img/banners/`のGIFを通す）。
  - フォントを太くすると「m」のすき間が埋まった。手で置いた字なら潰れない。
  - 最初は1998年のO-netの広告（人物が並び、呼びかけの文が替わる形）にならったが、とぼけがおが個人サイトのバナーの形を選んだ。
- **守り方**:
  - バナーの中の劣化やディザは、バナーの画像の中だけの例外にする。サイトのCSSには持ち込まない。
  - バナーは拡大も縮小もせず、1ドットを画面の画素の整数倍（`--u`）で表示する。
  - 字を足すときは`link_letters.py`に1字ずつ打ち、4倍に拡大して確かめる（`--zoom`）。
