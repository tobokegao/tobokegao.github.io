# 0049 Tobo Exciterのデモ動画は、ファイルをサイトに置いて出す

- **日付**: 2026-11-21
- **決めたこと**: `/toboexciter/`のデモ動画は、元のMP4（約5MB）を`static/toboexciter/`に置き、ショートコード`video`の`<video>`で出す。表紙の絵は表示する大きさのWebPにして`static/img/toboexciter/`に置く。CSPは変えない（`default-src 'self'`のままで、サイトにある動画は再生できる）。
- **理由**:
  - 動画サイトやXに上げると音声が圧縮し直され、ノイズが乗ることがある。エキサイターは高い音を足すエフェクトなので、元の音のまま聴けるようにした。
  - GitHubのReleasesにある同じファイルは、別のホストへ転送されてダウンロードになるので、ページの中では再生できない。
- **守り方**:
  - `preload="none"`にして、再生ボタンを押すまで動画を読み込まない。日本語と英語の両方にプレーヤーがあっても、読み込みは増えにくい。
  - `poster`は`relativeURLs`が書き換えないので、ショートコードがページから見た相対のパスで書く。
  - リポジトリが重くなるので、置く動画は短いものに限る。長いものは動画サイトに置く（0028、0039）。
  - プラグインの新しいバージョンでデモ動画が変わったら、このファイルと表紙の絵も入れ替える。
