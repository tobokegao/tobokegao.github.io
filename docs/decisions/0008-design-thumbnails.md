# 0008 デザインの一覧には小さい画像を出す

- **日付**: 2026-09-30
- **決めたこと**:
  - デザインのページでは、フライヤーを幅 480px の WebP に縮めて出す。押すと元の大きさの画像が開く。
  - 元の画像は `static/img/designs/` に置いたまま、`hugo.toml` の `[module]` で `assets/img/designs/` にも見せる。縮めるのは Hugo（`design-card.html` の `.Resize`）に任せる。
- **理由**:
  - フライヤーが 31 枚、合わせて 5.6MB あり、ページを開くのが重かった。縮めると 1.4MB になる。
  - 画像を `assets/` に移すと、活動ログなど `/img/designs/…` を直接指している所が切れる。置き場所を変えずに済むよう、同じフォルダを両方から見せることにした。
  - 縮めた画像を手元のスクリプトで作る案もあったが、フライヤーを足すたびに作り直す手間が増えるのでやめた。
- **守り方**:
  - フライヤーを足すときは、これまでどおり `static/img/designs/` に入れるだけでよい。
  - `[module]` の mounts を書くと、Hugo の標準の `assets` と `static` も書き足す必要がある。消さない。
  - 480px はカードの幅（約 240px）の 2 倍。カードの幅を変えたら見直す。
