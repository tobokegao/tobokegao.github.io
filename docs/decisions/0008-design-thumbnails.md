# 0008 デザインの一覧には小さい画像を出す

- **日付**: 2026-09-30
- **決めたこと**:
  - デザインのページでは、フライヤーを幅480pxのWebPに縮めて出す。押すと元の大きさの画像が開く。
  - 元の画像は`static/img/designs/`に置いたまま、`hugo.toml`の`[module]`で`assets/img/designs/`にも見せる。縮めるのはHugo（`design-card.html`の`.Resize`）に任せる。
- **理由**:
  - フライヤーが31枚、合わせて5.6MBあり、ページを開くのが重かった。縮めると1.4MBになる。
  - 画像を`assets/`に移すと、活動ログなど`/img/designs/…`を直接指している所が切れる。置き場所を変えずに済むよう、同じフォルダを両方から見せることにした。
  - 縮めた画像を手元のスクリプトで作る案もあったが、フライヤーを足すたびに作り直す手間が増えるのでやめた。
- **守り方**:
  - フライヤーを足すときは、これまでどおり`static/img/designs/`に入れるだけでよい。
  - `[module]`のmountsを書くと、Hugoの標準の`assets`と`static`も書き足す必要がある。消さない。
  - 480pxはカードの幅（約240px）の2倍。カードの幅を変えたら見直す。
