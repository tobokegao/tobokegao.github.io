# 0030 Xのポストとリポストは、1日1回Windowsのタスクで取り込み、プレビューまで出す

- **日付**: 2026-10-19
- **決めたこと**: Xの新しいポストとリポスト（0029）は、とぼけがおのPCのWindowsのタスクスケジューラーから1日1回、`scripts/x_daily.ps1`で取り込む。中では、Claude Codeを画面なしで動かし（`claude -p --chrome`）、`scripts/x_daily_prompt.md`の手順に沿わせる。点検（`check.py --all`）が通れば、`data/memo/`だけをコミットし、プレビュー（tbk-preview）に出す。本番には出さない（とぼけがおが頼んだときだけ）。
  - ブラウザで拾う部分は`scripts/x_profile_collect.js`、その前後は`scripts/x_daily.py`（`known`と`merge`）にまとめた。毎日のClaudeは、手順書と同じことしかしない。
  - 使える道具は、`x_daily.ps1`の`--allowedTools`に並べたものだけ（Chromeの読み取り、決まったスクリプト、`data/memo`のコミット、プレビューへのpush）。
  - 報告と記録は`work/x/daily/<日付>.md`と`.log`に残す。ログ（NEWS.LOG）に載せるかどうかは、とぼけがおが候補から選ぶ。
- **理由**:
  - リポストは1日に数十件あり、まとめて取ると1回に千件近くになる（10/19の初回は981件で、fxtwitterから中身を取るのに数十分かかった）。毎日少しずつなら、Xの読み込みも、fxtwitterへの問い合わせも少なくて済む。
  - Xを読むには、とぼけがおのログイン済みのChromeが要る。クラウドのスケジュール実行では、このChromeを使えない。Claudeのセッションの中の予約は、セッションを閉じると消え、7日で切れる。
  - 0004の「定期実行はしない」は、リリース、動画、ニュースのデータの決まり。メモはとぼけがおの頼みで例外にした（2026-10-19）。本番に出す前に人が見る、という0004の考えは、プレビューで止めることで守る。
- **守り方**:
  - Xでは読むだけ。書き込み、ログイン、設定の変更をしない。手順書にもそう書いてある。
  - `x_daily_prompt.md`を変えたら、`x_daily.ps1`の`--allowedTools`も見直す。
  - Chromeが閉じていたり、Xからログアウトしていたりすると、その日は取れない。報告にそう残るので、次の日に取り戻せる（知っている番号に行き当たるまでさかのぼるため）。
