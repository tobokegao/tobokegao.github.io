# 0015 カードのジャケットとサムネイルはサイトに置く

- **日付**: 2026-10-01
- **決めたこと**:
  - リリースのカードのジャケット（300×300）と動画のカードのサムネイル（320×180）は、`scripts/cover_cache.py` で取ってきて、表示する大きさの WebP にして `static/img/covers/` に置く。どの画像がどの外の URL の代わりかは `data/covers.json` に書く。
  - カード（`release-card.html`、`video-card.html`）は、対応表にある画像は手元のものを使い、ないものは今までどおり外の URL を使う。
  - データ更新のワークフロー（`update.yml`）は、`fetch_feeds.py` のあとにこの台本を動かし、新しい画像も同じ PR に入れる。
  - ログの行のページに出す大きな絵（`row-pic.html`）と、拡大表示は、今までどおり外の URL のまま。
- **理由**:
  - カードの画像は 5 か所の外のサーバー（SoundCloud、Bandcamp、YouTube、niconico、Apple）から取っていて、サーバーごとにつなぎ直す手間があった。とぼけがおのスマホでは、初めて見る画像が出るまでが遅かった。
  - サイトに置けば、ページと同じつながりでまとめて届き、大きさも表示どおりに作れる。外のサーバーの都合（URL が変わる、画像が消える）にも左右されない。読む人の端末から外のサーバーへ通信が行かない。
  - 大きさは 335 枚で約 4.5MB。GitHub Pages の限度には遠い。
- **守り方**:
  - 画像を足すときは表示する大きさの WebP にする（CLAUDE.md）。カードの表示サイズを変えたら、`cover_cache.py` の `JACKET` / `THUMB` も変えて `--refresh` で作り直す。
  - 対応表の鍵は外の URL そのもの。外の URL が変わった画像は手元のものが使われなくなるだけで、壊れはしない。`cover_cache.py` を動かせば取り直す。
  - 使われなくなった画像は `--prune` で消す。
  - `head.html` の CSP の `img-src` は、ログのページと予備のために外のホストを残す。
