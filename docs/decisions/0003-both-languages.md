# 0003 日本語と英語を一つのページに持つ

- **日付**: 2026-09-27
- **決めたこと**: どのページにも日本語と英語の両方を入れ、CSS で片方だけを見せる。JP / EN の切り替えは一つのボタンで、ページを読み直さない。
- **理由**: 切り替えをすぐに済ませたかった（とぼけがおの指定）。言語ごとに別のページにすると、切り替えのたびにページを読み直すことになる。
- **守り方**: 文言は `data/strings.toml` に両方の言語で書く。画像の代替テキストのように CSS で切り替えられないものは、言語ごとに 1 つずつ置き、隠れている側は `loading="lazy"` にして読み込まないようにする。
