# 0039 ReaScratchのページの英語表示では、デモ動画をYouTubeで出す

- **日付**: 2026-10-22
- **決めたこと**: `/reascratch/`のデモ動画は、日本語の表示ではニコニコ動画、英語の表示ではYouTubeのプレーヤーを出す（ショートコード`nico`の2つめの引数がYouTubeの動画の番号）。YouTubeは`https://www.youtube-nocookie.com`から埋め込み、CSPの`frame-src`にこれだけを足す。0028の「ほかのサイトの埋め込みは許さない」は、この1つを除いて続ける。
- **理由**:
  - 英語で読む人には、ニコニコ動画よりYouTubeのほうがなじみがあり、開きやすい。
  - youtube-nocookieは、再生するまでYouTubeのクッキーを置かない。
- **守り方**:
  - 2つのプレーヤーは`data-l`で表示を切り替える。隠れているほうのプレーヤーも、ブラウザによっては読み込まれる。
  - 埋め込む先を増やすときは、この記録のようにCSPと理由を残す。
