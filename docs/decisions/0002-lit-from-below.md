# 0002 下から黄色で照らす

- **日付**: 2026-09-28
- **決めたこと**: サイト全体を、とぼけがおの黄色で下から照らしている設定にする。影は真上に網点（チェッカー）で落とし、立体の縁は上を暗く、下を明るくする。検索欄も同じ。
- **理由**: ゲーム『Jazz Jackrabbit 2』のような見た目にしたかったため。黄色そのままでは強すぎたので、明るい縁は昼 #ece4c4、夜 #48463bにやわらげた。
- **守り方**: リンクのアイコンにホバーしたときは箱を出さず、アイコン自体が下からの光を多く受ける描き方にする（`scripts/hd_icons.py`の`.px__hl`）。例外はBotBのアイコンで、ポスターに合わせて影を下に落とす。夜の光の段階は`hd_icons.py`と`night_logos.py`でそろえる。
