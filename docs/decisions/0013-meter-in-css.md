# 0013 読み込みのメーターを CSS のアニメーションで動かす

- **日付**: 2026-10-01
- **決めたこと**:
  - `LOAD.EXE` のメーター（0010）を、スクリプトのタイマーで 1 マスずつ描くのをやめ、CSS のアニメーション（窓は `opacity`、メーターは `transform`）で動かす。進み方（0.3 秒で窓が出る、はじめは 0.04 秒で 1 マス、14 マスから先は 0.3 秒で 1 マス、19 マスで止まる）は前と同じにする。
  - 窓はリンクを押したときにすぐページに置き、見えるのは 0.3 秒たってからにする。
  - 次のページを組み立てる前に、画面が 1 回描かれるのを待つ（`site.js` の `afterPaint`）。
- **理由**:
  - Android の Chrome で、読み込みに 0.3 秒以上かかってもメーターが出ないことが多く、出ても前半の進みがとても遅い、ととぼけがおが気づいた。
  - 次のページの組み立て（とくに NEWS は部品が約 6,400 個）は、スクリプトの手をふさぐ。そのあいだはタイマーが動かないので、メーターを出す番も、描き足す番も回ってこなかった。`opacity` と `transform` のアニメーションは、スクリプトの手がふさがっていても、ブラウザが進められる。
- **守り方**:
  - メーターの進み方を変えるときは、`site.css` の `@keyframes loading-fill` を直す。1 回の動きは 5%（20 マスのうち 1 マス）の倍数にして、マスの途中で止まらないようにする。
  - 「視差効果を減らす」の設定の人には、前と同じく止まったまま（空のメーター）出す。
