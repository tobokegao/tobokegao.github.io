# 0013 読み込みのメーターをCSSのアニメーションで動かす

- **日付**: 2026-10-01
- **決めたこと**:
  - `LOAD.EXE`のメーター（0010）を、スクリプトのタイマーで1マスずつ描くのをやめ、CSSのアニメーション（窓は`opacity`、メーターは`transform`）で動かす。進み方（0.3秒で窓が出る、はじめは0.04秒で1マス、14マスから先は0.3秒で1マス、19マスで止まる）は前と同じにする。
  - 窓はリンクを押したときにすぐページに置き、見えるのは0.3秒たってからにする。
  - 次のページを組み立てる前に、画面が1回描かれるのを待つ（`site.js`の`afterPaint`）。
- **理由**:
  - AndroidのChromeで、読み込みに0.3秒以上かかってもメーターが出ないことが多く、出ても前半の進みがとても遅い、ととぼけがおが気づいた。
  - 次のページの組み立て（とくにNEWSは部品が約6,400個）は、スクリプトの手をふさぐ。そのあいだはタイマーが動かないので、メーターを出す番も、描き足す番も回ってこなかった。`opacity`と`transform`のアニメーションは、スクリプトの手がふさがっていても、ブラウザが進められる。
- **守り方**:
  - メーターの進み方を変えるときは、`site.css`の`@keyframes loading-fill`を直す。1回の動きは5%（20マスのうち1マス）の倍数にして、マスの途中で止まらないようにする。
  - 「視差効果を減らす」の設定の人には、前と同じく止まったまま（空のメーター）出す。
