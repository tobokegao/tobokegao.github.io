# 設計判断の記録

サイトの作りを決めたときの「なぜそうしたか」を、1件1ファイルで残す。
コミットの履歴にも残るが、文言の修正や小さな追加に埋もれて探しづらいので、大事な判断だけをここに集める。

## 書き方

- ファイル名は`番号-短い名前.md`（例: `0007-font-grid.md`）。番号は続きから振る。
- 中身は次の4つ。長く書かない。
  - **日付**: 決めた日
  - **決めたこと**: 何をどうするか
  - **理由**: なぜそうしたか。試してやめた案があれば、それも書く
  - **守り方**: 作業のときに気をつけること
- 判断を変えるときは、古い記録を消さずに「0009で変更」のように書き足し、新しい記録を足す。
