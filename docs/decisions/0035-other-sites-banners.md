# 0035 リンク先のバナーは写しを置き、縦40にそろえ、小さいボタンは別の列に実寸で並べる

- **日付**: 2026-10-21
- **決めたこと**: LINKS.HTMの「リンク先」に、ほかのサイトのバナーを並べる。一覧は`data/link_sites.toml`、画像は`static/img/links/`に置く。
  - 画像は相手のサイトから取った写しを置き、直リンクはしない。表示する大きさのWebPにする。
  - 200×40のバナーはそのまま並べる。ほかの大きさのものは、形を保ったまま縦40にそろえ、横幅は整数のpxに丸める。元の画像の縦が80以上あれば、高精細の画面用に2倍の写し（`img2x`）も作る。並びは左寄せ。
  - 88×31や100×35のような小さいボタンは、`small = true`で別の列に実寸で並べる。高さ31と35のボタンは、拡大も縮小もせず、同じ中心の線にそろえる。
  - 動くバナーは動くWebPにし、1コマ目だけの写し（`still`）も置く。動きを減らす設定の人には`still`を出す（自分のバナーと同じ）。
  - 相手が動く版と動かない版を配っているときは、動く版を選ぶ。
  - httpだけのサイトも、Internet Archiveではなく今のサイトにリンクする（ブラウザの警告は出るが、サイトは生きていて、写しへのリンクでは相手に人が行かない）。
  - 載せるのは、相互フォローか、とぼけがおが知っている人のサイト。相手がバナーやボタンを配っていないとき、またはリンクの決まりが見当たらないときは、本人に確かめてから載せる。
- **理由**:
  - 直リンクを断っているサイトがある（megahack.net、MusMus、happy busyなど）。写しなら相手の転送量も使わない。
  - 横200にそろえると、200×62や200×70のバナーが一回り大きく見え、列の高さもでこぼこになった。縦40なら200×40と上下の線がそろう。
  - 31と35を同じ高さに伸び縮みさせると、整数倍でなくなり、ドットがにじむ（サイトの決まりに反する）。
  - バナーは、Xのアーカイブの相互フォロー（やりとりの多い順）のプロフィールのURL、ポストに出てきたサイト、載せたサイトのリンクのページをたどって探した。順位が下がるほど見つかる数が減ったので、900位で止めた（スクリプトは`work/links/`の作業用で、リポジトリには置かない）。
- **守り方**:
  - 相手がバナーを描き直したら、写しを取り直す。ファイル名は`static/img/links/<名前>.webp`のまま上書きする。
  - 1サイト1枚。200×40があればそれを、なければそれより小さいものを、大きいものしかないときだけ大きいものを使う。
  - 小さいボタンの列の画像は、拡大も縮小もしない。
