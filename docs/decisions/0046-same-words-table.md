# 0046 ミニとぼけがおは、同じ意味の語の表で、書き方の違う語もまとめて探す

- **日付**: 2026-11-06
- **決めたこと**: 同じ意味で書き方の違う語（「セットリスト」「セトリ」「setlist」「set list」）を、手で書いた表（`data/minitobo_words.toml`）にまとめる。ミニとぼけがお（`notes.js`の`initMini`）は、質問にどれかの語があれば、組のどの語が入ったポストも同じに探す。
  - 組の語は、質問を語に切る前に取り出す（「セットリスト」が「セット」と「リスト」に切られないように）。組が見つかったときは、残りの言葉からひらがなだけの語などを除く（0045と同じ決まり）。
  - Pagefindは渡した語が全部あるページしか返さないので、組の語ごとに探して、見つかったページをまとめる。探す回数は1回の質問で8回まで。
  - 点を付けるときは、組のどれかの語があれば当たったとみなす。重さは組の中でいちばん重い語に合わせる。答えでは、組の語すべてに印を付ける。
  - 英字の語は単語として比べる（「nes」は「business」に当てない）。
  - 答えの種類を表す語（「ライブ」「リリース」「おすすめ」「好き」）は、先に質問から外すので、表に入れない。
- **理由**:
  - 「セットリスト」で聞くと、「setlist」と書いたポストが見つからなかった（2026-11-06）。メモには「セットリスト」81件、「セトリ」85件、「setlist」105件があり、どれで聞いてもほかの書き方を取りこぼしていた。
  - カタカナをローマ字に直して比べる方法は、「セットリスト」が「settorisuto」になり、「setlist」と一致しないのでとらなかった。
  - `post_topics.py`で全部のポストに両方の言葉の語を付け直す方法は、APIの料金がかかり、質問の書き方の違いも残るのでとらなかった。
- **守り方**:
  - 取りこぼしに気づいたら、表に組を足す。語はポストに書かれている形で、英字は小文字で書く。
  - 短い語や、別の意味でも使う語（「mix」「レコード」）は、関係のないポストに当たりやすいので入れない。
