# 0041 リンクのカードを英語で出すための、小さな英語のページを置く

- **日付**: 2026-10-26
- **決めたこと**: どのページにも、`/en/<元のパス>/`に小さな英語のページを作る（例: `/en/post/2026-tobokegao-and-chiptune/`）。中身は英語の題名、説明、絵（`og:`のタグ）だけで、開いた人はすぐ元のページへ`?lang=en`付きで移り、`early.js`が英語の表示に切り替えてアドレスから`?lang=en`を消す。英語のカードを出したいときは、このURLを貼る。作るのは`hugo.toml`の出力形式`card`と`layouts/all.card.html`、題名と説明を決めるのは`layouts/_partials/meta.html`（日本語のページの`head.html`と同じもの）。
- **理由**:
  - Blueskyなどのカードは、相手のサーバーがHTMLを読んで作る。言葉の切り替えはページを開いたあとのスクリプトで行うので（0003）、カードはいつも日本語の題名と説明になっていた。
  - URLに`?lang=en`を付けても、GitHub Pagesは同じファイルを返すので、カードは変わらない。
  - どのページも丸ごと英語版を作ると、サイトが約420MB増えて約900MBになり、GitHub Pagesの上限（1GB）に近すぎる（2026-10-26に測った。ほとんどがメモのページ）。小さなページなら、4,788枚で約5MBで済む。
  - 本文は今までどおり1つのページに両方の言葉で持つ（0003のまま）。
- **守り方**:
  - 英語の題名は`title_en`、説明は`description_en`。ないときは日本語の題名と、トップと同じ「Welcome to TBK zone!」になる。英語のカードを出したいページには`description_en`を書く。
  - 小さな英語のページは検索に出さない（`noindex`と、元のページへの`canonical`）。
  - `/en/`には、昔のサイトの英語のトップからトップへ飛ばすファイル（`static/en/index.html`）があったが、トップの小さな英語のページが同じ役をするので消した。`static/en/`には何も置かない。
  - 題名や説明の決め方を変えるときは`meta.html`だけを直す。日本語と英語で同じ決め方になる。
