# 0001 DOSのテキスト画面の見た目

- **日付**: 2026-09-27
- **決めたこと**: サイト全体をDOSのテキスト画面（二重線の窓、メニューバー、Fキーのステータスバー）の見た目にする。角丸はどこにも使わない。昼はサイトの配色（淡い机、白い窓、紺の枠、ロゴの青、黄）、夜はTRACKMENTOの配色。
- **理由**: もともとのサイトが昔のパソコン（DOS）の文字画面のような雰囲気で、その世界観を壊したくなかったため。Windows Terminal風の案も試したが、採らなかった。昼の配色は黄色い背景の案も試したが、最初の試作の淡い机の配色に戻した。
- **守り方**: 窓のタイトルは本物の拡張子にする（README.TXT、RELEASES.M3Uなど）。メニューの項目名は日本語表示でも英語（Releases、Videos、Designs、News、Posts、About）。スマホでは6つのメニューを画面下のタブバーに置く（18pxのボタンは指で押しづらかったため）。
